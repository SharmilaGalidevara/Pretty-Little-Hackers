# 🚗 PARKMIND — Intelligent IoT Car Park Management System

*PARKMIND* is a smart, hardware-integrated car park management system designed to make parking *safer, smarter, more efficient, and predictive*.

Built for the *HackMY × IoT MyEvolution Hackathon 2026*, PARKMIND goes beyond basic parking automation by combining *real-time monitoring, IoT hardware control, predictive maintenance, intelligent gate management, and operator dashboards* into one connected platform.

### ✨ What We Built

* 🚧 *Smart Gate Management* — Automated entry/exit barriers with real-time vehicle flow monitoring.
* 🅿️ *Live Parking Monitoring* — Tracks parking availability and occupancy across the car park.
* 💡 *IoT Lighting Control* — Monitors and controls parking lights, including manual operator control.
* 🌀 *Smart Fan & Equipment Control* — Real-time monitoring with automated and manual operation.
* 🔧 *Predictive Maintenance* — Detects maintenance patterns and schedules servicing **before components fail**.
* 🖥️ *Interactive Operator Dashboard* — A compact, responsive interface where each system component can be expanded for detailed information.
* ⚡ *Real-Time Hardware Integration* — Software communicates with physical/simulated IoT components and responds to live system events.
* 🚨 *Fault & Repair Management* — Tracks component health, repair states, and maintenance activities.
* 📊 *System Analytics & Logs* — Provides operational visibility for faster troubleshooting and smarter decisions.

### 🧠 The Innovation

Instead of waiting for a gate, light, fan, or other component to **fail**, PARKMIND uses system activity and maintenance patterns to identify when servicing should happen — turning a reactive car park into a **proactive and intelligent infrastructure system**.

> *PARKMIND doesn't just manage a car park — it learns from it, monitors it, and helps prevent problems before they happen.* 🚀

### 🛠️ Technology

*Python • Flask • SQLite • REST APIs • IoT Hardware Integration • Real-Time Monitoring • Web Dashboard*

Built with a focus on *automation, reliability, scalability, and real-world IoT integration*.
